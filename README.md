# Modern Cybersecurity Student Portfolio

Premium, creative, responsive one-page portfolio for a cybersecurity student.

## Included
- Modern dark visual identity with neon lime/cyan accents
- Animated grid background and scrolling skills marquee
- Hero security profile card
- About, capabilities, projects, education/certifications, contact
- Mobile navigation
- Resume download button
- No framework; only HTML, CSS and JavaScript

## Personalize
Edit `index.html`:
1. Replace `Your Name`
2. Update degree/college/certifications
3. Replace skills with your actual tools
4. Replace project text and links
5. Replace email, LinkedIn, GitHub, TryHackMe/HTB
6. Put your own `resume.pdf` beside `index.html`

## Free hosting
Upload all files to a public GitHub repository and enable GitHub Pages under Settings → Pages.
